# Dragon Rider

[Download the Dragon Rider class ZIP](https://raw.githubusercontent.com/rempred/OB64-Animations/main/downloads/Dragon-Rider.zip). Extract it to get the `Dragon-Rider` folder with `class-animations.json` and all 17 numbered sequence folders.

Each sequence has a player rear-quarter view (`Player_Left`) and an enemy front-quarter view (`Enemy_Right`). Both use a 104 × 96 canvas with an anchor at (50, 75) from the top left. The index has 34 entries. Idle and Advance loop. Each reaction and recovery plays separately. T2 Breath uses gameplay attack 40 and donor pose 42.

The `Body` track contains the mounted rider and dragon. Draw one matching spear over it. All four tracks are available as numbered PNGs and individual `Timed.zip` files.
