# Dragon Rider

The 17 combat sequences each include a player rear-quarter view (`Player_Left`) and an enemy front-quarter view (`Enemy_Right`). Each frame uses a 104 × 96 canvas with an anchor at (50, 75), measured from the top left.

`Body` contains the mounted rider and dragon. Draw one matching equipment track over it: `Leaf_Spear`, `Bronze_Partisan`, or `Tide_Trident`. To switch weapons in-game, assign the track to a separate equipment layer in the destination unit. A whole-animation replacement flattens the imported artwork.

## Credits

The rider and dragon were rendered from the Dragonwing Adventurer and Fiery Dragon King models created with Meshy. The mounted gait adapts the T-Rex run from Quaternius's CC0 asset pack, [Animated LowPoly Dinosaurs](https://quaternius.itch.io/animated-lowpoly-dinosaurs).
